# Contributing

Suggestions and corrections are welcome. This list covers AI methods, datasets, benchmarks, and tools for physical sensor signals, including single-sensor work.

## Suggest a resource

Open a resource-suggestion issue or a focused pull request with:

- The title, authors, publication status, and primary-source link.
- The sensors involved and the main contribution.
- A concise account of demonstrated results and relevant limitations.
- Official code, model, or data links where available.

Write entries in English, avoid duplicate records, and disclose any affiliation with the work. Link to original sources rather than copying abstracts. Personal discussions and unpublished research plans belong in a separate project.

## Edit an entry

Update `data/catalog.json`; use `data/relationships.json` for documented method or data reuse. Regenerate the pages and run the local checks described in [MAINTAINING.md](MAINTAINING.md).
